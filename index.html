What's latest

AI as a force multiplier

Since 2023, AI has been a force multiplier in my work — not a gimmick. The real skill is using it reliably: knowing where it speeds things up, where it adds risk, and how to keep a human firmly in control of anything that matters.

Reading legacy code faster

AI-assisted analysis extracts business rules from decades-old COBOL in days, not weeks — surfacing logic that no documentation ever captured.

Documentation that keeps up

I use AI to turn complex technical work into clear discovery reports, mappings, and walkthroughs — so the knowledge is actually usable by the client.

Catching drift early

When moving logic from COBOL to Java, I use AI to reconcile the old rules against the new code — surfacing silent behaviour changes before they reach production.

Risk kept in check

Every AI output is validated, traced to source, and signed off by people. AI accelerates the work; it never gets the final say on anything critical.

“The goal is not to replace judgement with AI. It is to spend less time on the mechanical parts, so more time goes to the decisions that actually need a human.”

𝗔𝗴𝗲𝗻𝘁𝗶𝗰 𝗔𝗜 𝘀𝗼𝗹𝘂𝘁𝗶𝗼𝗻𝘀 𝘃𝘀. 𝘁𝗼𝗼𝗹𝘀 𝗯𝘂𝗶𝗹𝘁 𝗯𝘆 𝗮𝗴𝗲𝗻𝘁𝗶𝗰 𝗔𝗜 𝘀𝗼𝗹𝘂𝘁𝗶𝗼𝗻𝘀

𝗔𝗴𝗲𝗻𝘁𝗶𝗰 𝗔𝗜 𝘀𝗼𝗹𝘂𝘁𝗶𝗼𝗻𝘀 𝘃𝘀. 𝘁𝗼𝗼𝗹𝘀 𝗯𝘂𝗶𝗹𝘁 𝗯𝘆 𝗮𝗴𝗲𝗻𝘁𝗶𝗰 𝗔𝗜 𝘀𝗼𝗹𝘂𝘁𝗶𝗼𝗻𝘀

Today's challange: For a code migration project, do I let AI Agents handle every task directly, or do I use AI agents to build a tool that then handles the migration?

Both are viable. Factors I am considering -

𝗙𝗶𝗿𝘀𝘁, 𝘁𝗵𝗲 𝗲𝗻𝗱 𝗴𝗼𝗮𝗹. A migration factory — where you're migrating code on an ongoing basis — favors building a reusable tool. The engineering cost is paid once, and every subsequent run is fast and cheap. A one-time migration favors using agentic AI directly, since building and maintaining a tool for a single use isn't worth the investment.

𝗦𝗲𝗰𝗼𝗻𝗱, 𝗵𝗼𝘄 𝗺𝘂𝗰𝗵 𝗱𝗲𝘁𝗲𝗿𝗺𝗶𝗻𝗶𝘀𝗺 𝘁𝗵𝗲 𝘁𝗮𝘀𝗸 𝗻𝗲𝗲𝗱𝘀. Code translation benefits from deterministic parsers — the same input should produce the same output every time. Document generation and business rule extraction are less structured and benefit more from agentic reasoning, where judgment matters more than repeatability.

𝗧𝗵𝗶𝗿𝗱, 𝘁𝗼𝗸𝗲𝗻 𝗲𝗰𝗼𝗻𝗼𝗺𝗶𝗰𝘀 (𝗜𝗺𝗽𝗼𝗿𝘁𝗮𝗻𝘁 𝘁𝗵𝗲𝘀𝗲 𝗱𝗮𝘆𝘀 :𝗣). A tool only calls an LLM when it breaks or needs an upgrade. An agentic pipeline calls one for every task, every run. Over hundreds of migrations, that difference adds up fast.

I am landing on a hybrid: structured input, like XML source files, goes through a deterministic parser. Where actual knowledge is needed — understanding what's implemented, generating the business rule behind it — we use agentic AI. The tool does the repeatable work; the agents build and refine the tool, and step in where judgment is required.

Interested to hear how others are approaching this split on their own projects, or where you've run into problems with either approach.

How I think

Principles I keep coming back to

A few ideas I keep coming back to — in work and otherwise.

01

Learn by doing real things

I get good at something by taking on a concrete problem and seeing it through — depth first, learning what I need as I need it. Then I explain it in my own words until it's genuinely mine.

02

Fail forward

Setbacks are data, not defeat. I'd rather try, be wrong early, and adjust quickly than play it safe and learn nothing. Ownership over blame, every time.

03

The goal isn't to be right — it's to get it right

I change my mind when the facts change. Holding a view lightly and updating it isn't weakness; it's how you avoid being confidently wrong.

04

Old doesn't mean obsolete

The most dangerous assumption in enterprise IT is that legacy means worthless. These systems still run the world for a reason. Respect what works, then improve it carefully.

05

People and process first, technology second

Every transformation is a people and process problem before it's a technology one. The best technical answer is the one the business can actually sustain.

06

Measure against who I was

I compare myself to my younger self, not to other people. Am I better than I was last year? That's the only scoreboard that keeps me honest.
